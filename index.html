Memory-Efficient ML-based Prefetch Filtering (UG Thesis) February 2024 – March 2025
Advisor: Dr. Rifat Shahriyar, BUET
  • Developed a Neural Network-based Prefetch Filtering algorithm and a training & testing pipeline in the ChampSim cache simulator; compared with the existing Perceptron-based filter (PPF).
  • Achieved a reduction of 93% in model weights and 47% in total memory overhead while keeping performance almost the same as the reference model.
  • Significantly improved Coverage compared to the baseline prefetcher without any significant loss of Accuracy.
